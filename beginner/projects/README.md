# 🏆 Module 12: Beginner Capstone Projects

Welcome to the **Beginner Capstone Projects** module! This module marks the culmination of **Level 1: Beginner Python Curriculum**.

---

## 🎯 Purpose of Capstone Projects

True programming mastery is not measured by reading tutorials or memorizing syntax; it is developed through **building real, functional software from scratch**.

These 8 comprehensive capstone projects synthesize every concept covered across Modules 1 through 11:
- Fundamental types, expressions, and string operations
- Branching logic, loops, and pattern matching
- Built-in collections (lists, tuples, dicts, sets) and comprehensions
- Modular function architecture, parameters, and variable scoping
- Standard library modules (`random`, `secrets`, `datetime`, `math`, `json`, `csv`)
- File handling, context managers, and `pathlib`
- Robust error handling with custom exceptions and validation

---

## 📑 Project Catalog

Each project includes complete architectural requirements, component designs, step-by-step implementation blueprints, full runnable production source code, test suites, and extension challenges.

1. **[01 — Interactive CLI Scientific Calculator](01-cli-calculator.md)**
   - Operators, arithmetic precision, math library, dictionary dispatch, and recursive evaluation.
2. **[02 — Number Guessing Game with Adaptive Difficulty](02-number-guessing-game.md)**
   - Randomness, binary search hints, game loops, high-score file persistence, and input validation.
3. **[03 — Persistent To-Do & Task Manager CLI](03-todo-list-manager.md)**
   - JSON file persistence, task state transitions, priority sorting, filtering, and CLI interface.
4. **[04 — Cryptographically Secure Password Vault Generator](04-password-generator.md)**
   - `secrets` CSPRNG, character set entropy calculation, strength auditing, and CSV export.
5. **[05 — Persistent Contact Book & Phonebook Engine](05-contact-book.md)**
   - CSV database storage, regex contact validation, search indexing, and deduplication.
6. **[06 — Personal Expense & Budget Tracker](06-expense-tracker.md)**
   - Category aggregations, monthly analytics, datetime tracking, formatted tabular reporting, and CSV ingestion.
7. **[07 — Interactive Timed Quiz & Flashcard Engine](07-quiz-application.md)**
   - JSON question bank parsing, randomized question sampling, timed scoring, and performance reporting.
8. **[08 — Terminal Weather & City Forecast Client](08-weather-cli.md)**
   - HTTP API client simulation/integration, JSON payload destructuring with `match/case`, temperature unit conversions, and ASCII weather dashboards.
