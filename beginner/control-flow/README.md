# 🔀 Module 5: Control Flow

Welcome to the **Control Flow** module. Control flow structures determine the order in which code instructions are executed, enabling programs to make decisions, repeat operations, and dynamically route execution paths based on runtime data.

---

## 🎯 Module Overview

Without control flow, computer programs would be linear sequences of single-use statements. This module equips you with the complete suite of Python control flow primitives: branching conditionals (`if`, `elif`, `else`), conditional ternary expressions, sequence iteration with `for` loops and `range()`, condition-driven iteration with `while` loops, loop jump controls (`break`, `continue`, `pass`), loop `else` clauses, and modern **Structural Pattern Matching (`match`/`case`)** introduced in Python 3.10.

---

## 📑 Articles in this Module

1. **[Conditional Statements](conditional-statements.md)**
   - `if`, `elif`, `else` execution hierarchies, indentation rules, nesting vs flat guard clauses, and conditional ternary expressions (`x if cond else y`).
2. **[For Loops & The Iteration Protocol](for-loops.md)**
   - Definite iteration, `range(start, stop, step)`, iterating over sequences, mappings, and sets, nested loops, and the Python iteration protocol.
3. **[While Loops](while-loops.md)**
   - Indefinite iteration, condition evaluation, sentinel loops, infinite loops (`while True`), loop state progression, and avoiding deadlocks.
4. **[Break, Continue & Pass](break-continue-pass.md)**
   - Early loop termination (`break`), skipping iterations (`continue`), no-op placeholders (`pass`), and the unique Python **Loop `else` clause** (`for...else`, `while...else`).
5. **[Structural Pattern Matching](match-case.md)**
   - Modern Python 3.10+ `match`/`case` syntax, literal patterns, capture patterns, wildcard `_`, sequence patterns, mapping patterns, class patterns, and `if` guard expressions.
