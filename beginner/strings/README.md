# 📝 Module 4: Strings in Depth

Welcome to the **Strings in Depth** module. Text processing is fundamental to almost every software discipline, from generating user interface messages to parsing massive datasets, building web APIs, and constructing command-line tools.

---

## 🎯 Module Overview

While primitive string creation was introduced in Module 2, professional Python development requires deep fluency in string formatting paradigms, string manipulation methods, zero-copy slicing, and text normalization. This module explores modern formatted string literals (f-strings), format specifiers, slicing algorithms with negative strides, and the full catalog of built-in string methods.

---

## 📑 Articles in this Module

1. **[String Formatting](string-formatting.md)**
   - Evolution of formatting in Python: `%`-formatting, `str.format()`, Formatted String Literals (f-strings, PEP 498), format specifiers (alignment, padding, precision, sign, radix, dates), expression debugging with `f"{expr=}"`, and Python 3.12 formalized f-strings (PEP 701).
2. **[String Methods](string-methods.md)**
   - Comprehensive exploration of string transformation methods: case conversion (`lower`, `upper`, `title`, `casefold`), search & count (`find`, `index`, `count`, `startswith`, `endswith`), stripping & cleaning (`strip`, `lstrip`, `rstrip`, `removeprefix`, `removesuffix`), splitting & joining (`split`, `rsplit`, `splitlines`, `join`), and character type validation (`isalpha`, `isdigit`, `isalnum`, `isspace`).
3. **[String Slicing & Indexing](string-slicing.md)**
   - Zero-based indexing, positive and negative indices, the slice syntax `[start:stop:step]`, negative strides for string reversal, slice objects (`slice()`), boundary handling, and zero-copy substring mechanics.
