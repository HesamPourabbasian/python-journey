# ⚡ Module 3: Operators & Expressions

Welcome to the **Operators & Expressions** module. Operators are the foundational verbs of Python programming, enabling you to manipulate values, evaluate complex relational logic, perform bitwise operations, and control algorithmic evaluation order.

---

## 🎯 Module Overview

Python provides an expressive set of operators with well-defined mathematical and logical semantics. Mastering operators requires more than understanding basic addition and subtraction—it requires mastering operator precedence, short-circuit evaluation in boolean expressions, the mechanics of the walrus assignment operator (`:=`), bitwise manipulation, container membership lookup costs, and object identity comparison.

---

## 📑 Articles in this Module

1. **[Arithmetic Operators](arithmetic-operators.md)**
   - Addition (`+`), subtraction (`-`), multiplication (`*`), true division (`/`), floor division (`//`), modulo (`%`), exponentiation (`**`), operator precedence (PEMDAS), and the `operator` module.
2. **[Comparison & Logical Operators](comparison-logical-operators.md)**
   - Relational operators (`==`, `!=`, `<`, `<=`, `>`, `>=`), chained comparisons (`1 < x < 10`), logical operators (`and`, `or`, `not`), short-circuit evaluation mechanics, and operand return rules.
3. **[Assignment & Bitwise Operators](assignment-bitwise-operators.md)**
   - Standard assignment (`=`), augmented assignment (`+=`, `-=`, `*=`, etc.), the Walrus assignment expression operator (`:=`, PEP 572), and low-level bitwise operations (`&`, `|`, `^`, `~`, `<<`, `>>`).
4. **[Identity & Membership Operators](identity-membership-operators.md)**
   - Object identity testing (`is`, `is not`), container membership testing (`in`, `not in`), algorithmic time complexities ($O(1)$ in sets/dicts vs $O(N)$ in lists/tuples), and substring matching.
