# ⚙️ Module 1: Python Fundamentals

Welcome to the foundational module of the Python curriculum. This module establishes the mental model and physical tooling required to write, execute, debug, and isolate Python applications.

---

## 🎯 Module Overview

Before writing algorithms and building complex data pipelines, every engineer must understand the runtime environment, the nature of interpreted languages, bytecode compilation, and dependency isolation. This module provides a rigorous introduction to the Python ecosystem.

---

## 📑 Articles in this Module

1. **[What is Python?](what-is-python.md)**
   - High-level overview, design philosophy (PEP 20 - Zen of Python), interpreted vs compiled nature, dynamic typing principles, and ecosystem versatility.
2. **[Installing Python](installing-python.md)**
   - Cross-platform setup across macOS, Linux, and Windows; package managers (`brew`, `apt`), `pyenv` version management, and PATH configuration.
3. **[The Python Interpreter](python-interpreter.md)**
   - Interactive REPL, script execution mechanics, the compilation pipeline from Source Code $\rightarrow$ AST $\rightarrow$ Bytecode (`.pyc`) $\rightarrow$ CPython VM evaluation.
4. **[Python Versions & Evolution](python-versions.md)**
   - Python 2 vs Python 3 historical context, modern release lifecycles, deprecation policies, and modern Python 3.10–3.13 innovations.
5. **[Virtual Environments & Package Management](virtual-environments.md)**
   - Environment isolation mechanics, standard `venv` creation, dependency locking, `pip`, and avoiding global site-packages pollution.
