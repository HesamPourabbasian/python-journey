## 📑 Projects in this Module

1. **[01. Production FastAPI Enterprise Microservice](01-production-fastapi-microservice.md)**
   - Complete asynchronous microservice with Pydantic V2 validation, Asyncpg database pooling, Redis caching, structured JSON logging, Prometheus metrics, and multi-stage Docker containerization.
2. **[02. Real-Time Distributed WebSocket Chat Server](02-real-time-chat-websocket.md)**
   - Distributed WebSocket communication engine with Redis Pub/Sub cluster broadcasting, connection heartbeats, multi-room routing, and graceful disconnect management.
3. **[03. Distributed Asynchronous Task Queue](03-distributed-task-queue.md)**
   - Celery-inspired distributed background task queue built in pure Python and Redis, featuring task priority queues, exponential backoff retries, worker heartbeats, and Dead-Letter Queues (DLQ).
4. **[04. High-Performance Financial Data Pipeline](04-high-performance-data-pipeline.md)**
   - High-throughput streaming data analytics engine processing hundreds of thousands of financial market ticks with SIMD vectorization, memory downcasting, and anomaly detection.
5. **[05. Enterprise RAG AI Knowledge & Semantic Search Engine](05-rag-ai-search-engine.md)**
   - Production Retrieval-Augmented Generation (RAG) system with document chunking, dense vector embedding search, Pydantic structured output validation, and grounded answer synthesis.
